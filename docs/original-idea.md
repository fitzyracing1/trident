# Original idea (Joshua Almeida), verbatim

```
Import math
//logic gate//
Main
()
N;
<=0
```

Interpretation: `import math`; a logic gate in `main()` taking `N`; the gate checks `N <= 0`.
N is a module's capacity/health. If N <= 0 the module is out and its job is handed to another module that can do it.
